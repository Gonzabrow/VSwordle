# Product Overview

VSwordle - 1v1対戦型Wordleゲーム。2人のプレイヤーが同じ単語を同時に推測し合い、先に正解した方が勝利するリアルタイム対戦ゲーム。

## Core Capabilities

- **Wordle ゲームロジック**: 5文字の英単語推測、HIT/BLOW/ABSENT判定（重複文字対応）
- **リアルタイム対戦**: WebSocket経由で対戦相手のタイピング・推測をリアルタイム表示
- **クロスプラットフォーム**: Flutter Webビルドによるブラウザ対応（GitHub Pages）

## Target Use Cases

- **カジュアル対戦**: 友人とルームコードを共有して対戦
- **スキル競争**: 同じ単語を同時に推測し、速さと正確さを競う

## Value Proposition

- オリジナルWordleのシングルプレイを **1v1対戦** に拡張
- 相手の進捗がリアルタイムで見える **緊張感のある競技性**
- ブラウザのみで動作、 **インストール不要**
