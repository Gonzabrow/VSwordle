# Game Sync

リアルタイムでの対戦ゲーム状態同期機能。

## ADDED Requirements

### Requirement: Server-Side Answer Generation

サーバーはゲーム開始時に正答を生成しなければならない（SHALL）。正答はサーバー側でのみ保持し、クライアントには送信してはならない（MUST NOT）。

#### Scenario: ゲーム開始時の正答生成

- **GIVEN** 2人のプレイヤーがルームに参加している
- **WHEN** ゲームが開始される
- **THEN** サーバーはwordSetからランダムに5文字の単語を選択する
- **AND** 正答はサーバー側でのみ保持される
- **AND** 両プレイヤーに同じ問題が出題される

### Requirement: Guess Submission

システムはプレイヤーの推測をサーバーで検証しなければならない（SHALL）。

#### Scenario: 有効な推測の送信

- **GIVEN** ゲームが進行中である
- **WHEN** プレイヤーが5文字の有効な単語を入力してEnterを押す
- **THEN** クライアントは推測をサーバーに送信する
- **AND** サーバーは単語がwordSetに存在するか検証する
- **AND** サーバーは正答と比較してHIT/BLOW/ABSENTを判定する
- **AND** サーバーは結果を両プレイヤーにブロードキャストする

#### Scenario: 無効な推測の拒否

- **WHEN** プレイヤーがwordSetに存在しない単語を送信する
- **THEN** サーバーはエラーを返す
- **AND** クライアントは「Not in word list」エラーを表示する
- **AND** 推測回数にはカウントされない

### Requirement: Real-Time Opponent Display

システムは相手の状態をリアルタイムで表示しなければならない（SHALL）。

#### Scenario: 相手の推測結果表示

- **GIVEN** 対戦中である
- **WHEN** 相手が推測を送信する
- **THEN** システムは相手のWordGridに推測した単語と結果（HIT/BLOW/ABSENT）を表示する
- **AND** 表示は推測確定後1秒以内に反映される

#### Scenario: 相手の入力中表示

- **GIVEN** 対戦中である
- **WHEN** 相手が文字を入力中である
- **THEN** システムは相手のWordGridの現在行に入力中の文字を表示する
- **AND** 表示は200ms以内に反映される（デバウンス適用）

### Requirement: Win Condition

システムは先に正解したプレイヤーを勝者としなければならない（SHALL）。

#### Scenario: 正解による勝利

- **GIVEN** 対戦中である
- **WHEN** プレイヤーが正答を推測する
- **THEN** サーバーはゲームを終了する
- **AND** 正解したプレイヤーに「勝利」を通知する
- **AND** 相手プレイヤーに「敗北」を通知する
- **AND** 両プレイヤーに正答を表示する

#### Scenario: 両者6回失敗

- **GIVEN** 両プレイヤーが5回ずつ推測済みである
- **WHEN** 両プレイヤーが6回目も不正解となる
- **THEN** サーバーはゲームを終了する
- **AND** 両プレイヤーに「引き分け」を通知する
- **AND** 両プレイヤーに正答を表示する

#### Scenario: 一方のみ6回失敗

- **GIVEN** プレイヤーAが6回不正解となった
- **AND** プレイヤーBはまだ推測回数が残っている
- **WHEN** プレイヤーAの6回目の結果が確定する
- **THEN** ゲームは続行する
- **AND** プレイヤーAは推測できなくなる
- **AND** プレイヤーBが正解するか6回失敗するまで待機する

### Requirement: Disconnect Handling

システムは切断時に再接続を待機し、タイムアウトで敗北としなければならない（SHALL）。

#### Scenario: 一時的な切断からの復帰

- **GIVEN** 対戦中にプレイヤーの接続が切断された
- **WHEN** 30秒以内に同じプレイヤーが再接続する
- **THEN** サーバーはプレイヤーを同じルームに復帰させる
- **AND** 現在のゲーム状態を再送信する
- **AND** ゲームは続行される

#### Scenario: 再接続タイムアウト

- **GIVEN** 対戦中にプレイヤーの接続が切断された
- **WHEN** 30秒経過しても再接続がない
- **THEN** サーバーは切断したプレイヤーを敗北とする
- **AND** 相手プレイヤーに「勝利（相手が切断）」を通知する
- **AND** ゲームを終了する

### Requirement: Keyboard Status Sync

システムはキーボードの状態を各プレイヤーの推測結果に基づいて更新しなければならない（SHALL）。

#### Scenario: 自分のキーボード状態更新

- **GIVEN** 対戦中である
- **WHEN** 自分が推測を送信し結果が返される
- **THEN** キーボードの各キーの色が結果に基づいて更新される
- **AND** HIT > BLOW > ABSENT の優先度で色が決定される

#### Scenario: 相手のキーボード状態は独立

- **GIVEN** 対戦中である
- **WHEN** 相手が推測を送信する
- **THEN** 自分のキーボードの状態は変化しない
- **AND** 相手のキーボード状態は相手の画面でのみ更新される
