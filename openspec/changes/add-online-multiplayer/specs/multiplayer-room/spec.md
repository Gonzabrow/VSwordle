# Multiplayer Room

ルームベースのマルチプレイヤーマッチング機能。

## ADDED Requirements

### Requirement: Room Creation

システムはプレイヤーがルームを作成できる機能を提供しなければならない（SHALL）。

ルーム作成時に一意の4文字英大文字ルームコード（例: ABCD）を生成しなければならない（SHALL）。

#### Scenario: ルーム作成成功

- **WHEN** プレイヤーが「ルーム作成」を選択する
- **THEN** システムは新しいルームを作成する
- **AND** 4文字の英大文字ルームコードを生成する
- **AND** プレイヤーを待機画面に遷移させる
- **AND** ルームコードを画面に表示する

#### Scenario: ルームコードをコピー

- **WHEN** プレイヤーが待機画面でルームコードをタップする
- **THEN** システムはルームコードをクリップボードにコピーする
- **AND** コピー完了のトースト通知を表示する

### Requirement: Room Joining

システムはプレイヤーがルームコードを入力して既存のルームに参加できる機能を提供しなければならない（SHALL）。

#### Scenario: ルーム参加成功

- **GIVEN** 有効なルームコードが存在する
- **AND** ルームに空きがある（1人待機中）
- **WHEN** プレイヤーがルームコードを入力して参加を選択する
- **THEN** システムはプレイヤーをルームに追加する
- **AND** 両プレイヤーに対戦開始を通知する
- **AND** ゲーム画面に遷移する

#### Scenario: 無効なルームコード

- **WHEN** プレイヤーが存在しないルームコードを入力する
- **THEN** システムは「ルームが見つかりません」エラーを表示する
- **AND** プレイヤーは参加画面に留まる

#### Scenario: ルームが満員

- **GIVEN** ルームに既に2人のプレイヤーがいる
- **WHEN** 3人目のプレイヤーが参加しようとする
- **THEN** システムは「ルームが満員です」エラーを表示する

### Requirement: Room Lifecycle

システムはルームを適切なタイミングで作成・終了しなければならない（SHALL）。

#### Scenario: ゲーム終了でルーム終了

- **GIVEN** 対戦中のルームがある
- **WHEN** どちらかのプレイヤーが正解する、または両者が6回失敗する
- **THEN** システムはルームを終了状態にする
- **AND** 両プレイヤーに結果画面を表示する

#### Scenario: 全員退出でルーム削除

- **GIVEN** ルームにプレイヤーがいる
- **WHEN** 全てのプレイヤーがルームを退出する
- **THEN** システムはルームを削除する

### Requirement: Connection Status Display

システムはプレイヤーに接続状態を表示しなければならない（SHALL）。

#### Scenario: 接続状態の表示

- **WHEN** プレイヤーがルームまたは対戦画面にいる
- **THEN** システムは現在の接続状態（接続中/切断中/再接続中）を表示する

#### Scenario: 相手の接続状態表示

- **GIVEN** 対戦中である
- **WHEN** 相手プレイヤーの接続が切断される
- **THEN** システムは「相手が切断されました」と表示する
- **AND** 再接続待機のカウントダウン（30秒）を表示する
